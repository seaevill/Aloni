# M1 – Records, offline-first (plan, 2026-11-17)

Status: **PROPOSED – waiting for Bora's approval.** Nothing below is built yet.
Inputs used (advice, not decisions – the choices here are mine): `M1-inputs/techlead.md` (TL), `M1-inputs/product.md` (PM), `M1-inputs/ux-qa.md` (UX). `accounts-security-review.md` is about the account step and is already applied to `RUNBOOK.md`.

## 1. Goal

Bora can record his real farm **on the phone, offline**: parcels, plantings, products with label uses, stock, soil/water tests (PM §1, stories S1–S3). Everything survives airplane mode and reload. No Supabase/Cloudflare account is needed for any PR in sections 3.1–3.3; the last PR (live sync) waits for the accounts.

## 2. Scope

**In (PM §1 "Week 1 required" columns, TL §1):**
- Parcel: name, **pin + typed στρ.** (map later, optional), soft-archive.
- Planting: parcel, crop chip, lot label, area στρ, sown_on, status.
- Product: trade name, reg. no., type, unit, label photo (stored on the phone).
- Label use (per product × crop): dose min/max per στρ, PHI d, REI h, max apps, source. Each value is *empty / entered / "δεν αναγράφεται"*. Sign-off badge «Μη εγκεκριμένο».
- Stock: lots (batch, expiry with year, qty) and a movements ledger. Corrections are new rows, never edits or deletes.
- Soil/water test: date, lab, report photo, pH, EC (rest optional).
- Local schema v2 (UUID ids, snake_case, `farm_id`), one write path with an outbox, `apply_ops` + pull SQL tested on CI Postgres.
- Guardrails and UX gates in CI (section 4).

**Out (PM §4, plus my additions):** spray/harvest logging and stock decrement by jobs (M2); PHI/REI countdowns; weather, rules, notifications (M3/M4); worker accounts, costs, Κλούβες sync, sensors; OCR / any auto-fill of label values; prefilling labels from the prototype or "typical" doses; map drawing or ΟΣΔΕ code as a requirement to save a parcel; structured golden fixtures (TL §1 item 8) – they are rules work, so they move to the start of M3; applying any migration to Supabase.

## 3. Decisions (each also goes to `docs/DECISIONS.md` when Bora approves)

1. **Doses are decimal strings** exactly as typed (comma or dot accepted, stored canonical `0.025`, shown `0,025`). No `number` for label values. Comparisons (min ≤ max) use scaled-integer BigInt. No rounding anywhere on this path (TL §2, QA P0-1).
2. **Branded types:** `DosePerStr`, `PhiDays`, `ReiHours`, `MaxApps` only come from `parseLabelValue()` returning `Known<T>` (`known:false` = blocked). Deciding functions accept only `SignedLabelUse`, produced only by `requireSignOff()`. Sign-off stores agronomist name + date + a **hash of the label values**; any edit changes the hash, so the sign-off drops automatically (PM §2).
3. **Ids:** every row has a UUID. Demo rows get **UUIDv5** from a fixed namespace + the prototype id (`P1` stays as `legacy_id`), so re-import is stable and references (`parcel_id` etc.) are rewritten. The old `uid = farmId:id` key is removed (TL §4.2).
4. **DB name:** `aloni` (new). The old `aloni-farm` database is deleted on first start; it only held demo data (TL §4.1).
5. **One write path** `repo.put()` writes the row and its outbox entry in one transaction. Append-only tables accept insert/amend only. The **Demo farm never writes to the outbox** (TL §1.2).
6. **Photos:** kept as Blobs in IndexedDB, downscaled to ≤2000 px on the long edge (labels must stay readable). Uploaded later with Supabase Storage. Flagged in Bora's checklist (TL §4.8). Persistent storage is requested already (M0).
7. **No confirm dialogs.** Save at once, show a 5 s «Αναίρεση» toast. Delete = archive (`deleted_at`) with undo; append-only data gets «Διόρθωση» (UX §1).
8. **Map:** "Pin + type στρ." ships first and is the only path in Bora's checklist. MapLibre/Terra Draw/turf comes behind one `TILE_SOURCE` config that points at OSM **for development only** (OSM tile policy forbids heavy/offline use). The production provider is a question for Bora (section 6); the map PR is not merged to the checklist until it is answered.
9. **Prototype single dose → label min/max (provisional, until Bora answers Q1):** in the **Demo farm only**, the prototype's single dose is stored in `dose_max`; `dose_min` stays *unknown*. Nothing is silently copied to both, and demo label uses show «Μη εγκεκριμένο». For the real farm the form has two boxes and nothing is prefilled.
10. **Device id:** each phone gets a random `device_id` (needed by the outbox). Worker accounts/PINs stay out of M1, so Q2 does not block M1 but must be answered before M2.
11. **Live sync** (HTTP calls to Supabase) is the last PR and needs the accounts. Until then the app shows «N μη συγχρονισμένα» honestly and keeps working.

## 4. Guardrails and gates (TL §2, UX §2)

- `CODING_STANDARDS.md`: every safety rule in `CLAUDE.md` paired with the mechanism that enforces it.
- **ESLint in CI:** ban `Math.round/floor/ceil`, `toFixed` and `?? <number>` in label/dose/spray code and `rules-core`; ban `Date.now()/new Date()` in `rules-core`; ban JSX text / string literals outside `t()`; require `no-floating-promises`.
- **Vitest:** el/tr/en key parity (exists), every used `t()` key exists and no dead keys, `{n}` placeholders match, `formatDose('0.025') === '0,025'`, missing dose renders «—  άγνωστο», demo-isolation (outbox stays empty, real farm untouched), `rules-core` has its own test command.
- **Playwright WebKit 375×667:** `iphone()` helper; `ux-bar.spec.ts` (no horizontal scroll; every button/link/input ≥56 px high and ≥44 px wide; every visible text ≥14 px) for every route × el/tr/en incl. empty states; **axe** (serious/critical fail); offline flow (3 unsynced → reload → data still there); undo flow with no `dialog` event; screenshots per route × language × (normal/empty/offline), **always uploaded** as artifact `screens-<PR#>`.
- **PR template:** safety rules touched? · el/tr/en · 375 px e2e · DECISIONS · Turkish note · the 7-step Greek iPhone checklist (UX §3).
