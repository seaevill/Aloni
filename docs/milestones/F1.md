# F1 – Ταμείο: manual money ledger on the owner's phone (2026-11-23)

**Status: started on Bora's go («yazmaya başlayabilirsin», 2026-11-23).** Parent plan: `docs/plan/FINANCE-AND-GROWTH-PLAN.md` (§5 F1). Answers in effect: prices variable, veresiye needed (F2), export CSV + PDF (F3).

## Özet (Türkçe)
F1 = **Άλλα → Ταμείο**: elle gelir/gider kaydı, yıl seçimi, yılın sonucu (gelir, gider, net), aylara göre çubuklar, kategorilere göre liste. Kayıt silinmez; «Διόρθωση» yeni bir düzeltme satırı yazar, «Ακύρωση» kaydı iptal eder (iz kalır). Sadece **senin telefonunda** ve sadece sahip görür; işçiler hiç görmez. Demo çiftlikte uydurma örnek kayıtlar var, gerçek çiftlik boş başlar. Yedek (Αντίγραφο) para kayıtlarını da içerir. Fatura fotoğrafı, müşteri borcu (veresiye), otomatik kayıtlar ve muhasebeci çıktısı **sonraki aşamalarda** (F2, F3).

## Scope (in)
1. **Core** (`app/src/money/ledger.ts`, pure, unit-tested): categories, amount parsing into **integer cents** (no floats, max 2 decimals, Greek ambiguity refused like `parseDecimal`), entry builder with validation, amend/void chain (append-only), effective entries, `yearSummary` (in, out, net, 12 months, per category), years present. Money text only through `i18n/format.ts` (`formatMoney`), never rounded.
2. **Storage**: device-local setting `money:<farm>` (same pattern as `cuts:<farm>` and `customers:<farm>`), so it is in the backup file and never queued for sync in normal use. The screen says «μόνο σε αυτό το τηλέφωνο».
3. **Screen** (second PR): Άλλα → «Ταμείο» (owner app only; the worker app has no route to it), year picker, BigNum net + in/out, month bars, category list, entry list; «＋ Έσοδο» / «＋ Έξοδο» form (amount, category chips, date = today, optional crop, note); entry sheet with «Διόρθωση» (amending row) and «Ακύρωση» (void row) + 5 s undo; the line «Προσωπικό βιβλίο εσόδων–εξόδων, όχι λογιστικά βιβλία».
4. **Demo farm**: fictional entries only on the Demo farm (CLAUDE.md rule 4).

## Out (later phases)

## Risks
- The phone holds the only copy until F6 → the Backup reminder already counts settings; the screen repeats «μόνο σε αυτό το τηλέφωνο».
- Restoring a backup **onto a different farm id** re-queues the phone's local settings as owner-only `farm_settings` (existing behaviour for cuts/customers, `repo/backup.ts`). Owner-only on the server (0006 policy); acceptable for F1, revisited in F6.

## Greek checklist for Bora's iPhone (after the screen PR)
1. Άλλα → **Ταμείο** ανοίγει· γράφει «μόνο σε αυτό το τηλέφωνο».
2. **＋ Έξοδο** → 45,50 → «Καύσιμα» → Αποθήκευση· το έξοδο του μήνα δείχνει 45,50 €.
3. **＋ Έσοδο** → 120 → «Πωλήσεις» → Αποθήκευση· το καθαρό αλλάζει σωστά.
4. Πάτησε την εγγραφή → **Διόρθωση** → 40 → το σύνολο αλλάζει, η παλιά τιμή φαίνεται στο ιστορικό.
5. **Ακύρωση** → «Αναίρεση» μέσα σε 5 δευτ. φέρνει την εγγραφή πίσω.
6. Γράψε 1.000 → η εφαρμογή ρωτά (ασαφές)· γράψε 1000 → δεκτό.
7. Άλλαξε έτος· άνοιξε την εφαρμογή εργάτη (Demo): δεν υπάρχει Ταμείο.
