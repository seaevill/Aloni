## Scope now (no accounts needed)

1. **Repo layout:** `/app` (Vite + Preact + TS, plain CSS), `/packages/rules-core` (pure TS, empty skeleton + one smoke test), `/rules` (empty, `.gitkeep`), `/supabase/migrations`, `/supabase/functions` (placeholder), `.env.example`, `RUNBOOK.md` (Turkish, one page, draft).
2. **i18n:** flat `el.json` / `tr.json` / `en.json`, Greek is the default. Tab names, shell texts, demo-farm labels. Greek date/number formats via `Intl` (`el-GR`, Europe/Athens).
3. **PWA shell:** manifest, icons (from `reference/klouves`, placeholder until the name is decided), Workbox precaching (generated service worker), bottom tabs **Σήμερα/Today · Προϊόντα/Crops · Χωράφια/Parcels · Αποθήκη/Stock · Περισσότερα/More**. Empty screens, ≥56 px targets, ≥16 px text, safe-area insets for iPhone, `storage.persist()` request.
4. **Local DB + Demo farm import:** Dexie schema (parcels, crops, plantings, products, jobs, orders_weekly, alerts, recommendations, weather). Importer reads `reference/prototype/data.json`, loads it into a farm flagged `is_demo = true` ("Δοκιμαστικό αγρόκτημα / Demo çiftlik / Demo farm"). Real farm stays empty. Button in More: "Load demo farm" / "Remove demo farm". Data is never mixed (separate `farmId`). Doses are copied as-is, never rounded; missing label values stay `null` (= unknown/blocked).
5. **CI (GitHub Actions):** typecheck, Vitest (importer + i18n key parity + rules-core smoke), Playwright WebKit at 375 px (shell loads, 5 tabs, tab switching, demo import shows data, manifest valid). Red CI blocks the merge.
6. **SQL migrations (written, NOT applied anywhere):** numbered files in `/supabase/migrations` for the ~20 tables in TECH-SPEC §2, `server_seq` trigger, audit trigger, append-only guard on spray/harvest/stock tables, `has_role()` + RLS policies. SQL is syntax-checked locally against a throwaway Postgres only if one is available; otherwise flagged "unchecked".
