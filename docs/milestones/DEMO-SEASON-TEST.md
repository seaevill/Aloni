# Δοκιμή «Επίδειξη: πλήρης σεζόν» (για τον Bora, στο iPhone)

Όλα τα στοιχεία είναι **φανταστικά** και μένουν μόνο στην Επίδειξη· δεν αγγίζουν το πραγματικό σας κτήμα. Οι ημερομηνίες μετακινούνται κάθε φορά ώστε η σεζόν να τελειώνει «σήμερα». Οι ψεκασμοί χρησιμοποιούν τα **δείγματα προϊόντων** της εφαρμογής (όχι επίσημες ετικέτες)· οι δόσεις είναι αυτές που γράφει η εγγραφή ετικέτας του δείγματος, χωρίς στρογγυλοποίηση.

1. **Άλλα → Επίδειξη: πλήρης σεζόν (90 ημέρες)** → θα πρέπει να δείτε «Η επίδειξη φορτώθηκε.» και πάνω-πάνω την κίτρινη ταινία «Επίδειξη – φανταστικά στοιχεία».
2. **Σήμερα** → στην κορυφή θα πρέπει να δείτε την κάρτα «Το πιο σημαντικό σήμερα» (π.χ. «Άγνωστη αναμονή» για ένα χωράφι) και κάτω τα κουμπιά «Νέος ψεκασμός» και «Καταγραφή συγκομιδής».
3. **Σήμερα → Χωράφια (αριθμός)** → θα πρέπει να δείτε **7** χωράφια: Μεγάλος Κάμπος, Λάκκα, Πευκάκια, Ανατολικό, Κοντά στο Ρέμα, Ράχη, Μικρό Περιβόλι (σύνολο περίπου 70 στρ.).
4. **Σήμερα → Καλλιέργειες (αριθμός)** → θα πρέπει να δείτε **9** καλλιέργειες, καθεμία με τον αριθμό φυτειών της.
5. **Σήμερα → Κοπή σήμερα / Χωράφια χωρίς αναμονή** → θα πρέπει να δείτε ποιες φυτείες είναι ελεύθερες, ποιες περιμένουν (με ημερομηνία) και ποιες έχουν **άγνωστη** αναμονή (με τον λόγο).
6. **Σήμερα → Αύριο φεύγουν** (ή Άλλα → Παραγγελίες → Αποστολή ανά πελάτη) → στη ρόκα θα πρέπει να δείτε ότι **λείπουν κλούβες** και ότι η ρόκα είναι «σε αναμονή»: οι φυτείες σε αναμονή **δεν μετρούν** ως διαθέσιμες.
7. **Χωράφια → Μεγάλος Κάμπος** → θα πρέπει να δείτε το σχέδιο του χωραφιού με τα όρια των φυτειών και ένα ΚΑΕΚ που ξεκινά με **99…** μαζί με την ένδειξη «Επίδειξη – φανταστικός αριθμός». Δεν υπάρχει κουμπί αλλαγής.
8. **Χωράφια → Πευκάκια** → θα πρέπει να δείτε ψεκασμό **σήμερα** (η επανείσοδος τρέχει ακόμη) και τη ρόκα με ψεκασμό χθες (η αναμονή λήγει σε 2 ημέρες).
9. **Χωράφια → Ράχη** → ο ψεκασμός με προϊόν που έχει **ανυπόγραφη** ετικέτα πρέπει να δείχνει **άγνωστη αναμονή** (όχι ημερομηνία, όχι 0). Το ίδιο ισχύει για το πράσο (ετικέτα χωρίς μέγιστο αριθμό εφαρμογών).
10. **Χωράφια → οποιοδήποτε χωράφι → Λίπανση / Άρδευση** → θα πρέπει να δείτε τις καταγραφές με τη μορφή αζώτου όπως γράφτηκε και τις ώρες/m³ νερού· στο «Κοπή / καθαρισμός» τη μέθοδο και την ημερομηνία.
11. **Φυτά → Μαϊντανός** → θα πρέπει να δείτε 6 συγκομιδές, τον ρυθμό συγκομιδής και το πρόγραμμα λίπανσης με κείμενο «επίδειξης – το γράφει ο γεωπόνος» (όχι δικό μας κείμενο).
12. **Φυτά → Ημερολόγιο σεζόν** → θα πρέπει να δείτε σπορές και συγκομιδές ανά μήνα για την Επίδειξη.
13. **Αποθήκη → Συγκομιδή στην αποθήκη** → θα πρέπει να δείτε μόνο τις **πρόσφατες** κλούβες (της τελευταίας εβδομάδας), με ηλικία σε ημέρες· οι παλιότερες έχουν φύγει απευθείας.
14. **Αποθήκη → Μανδιπροπαμίδιο → Υπόλοιπο** → θα πρέπει να δείτε **0 L** (το απόθεμα τελείωσε με τον ψεκασμό). Σε κανένα προϊόν δεν υπάρχει εφεύρεση ετικέτας: ό,τι λείπει γράφει «άγνωστο».
15. **Αποθήκη → Ακεταμιπρίδη** → θα πρέπει να δείτε ότι η παρτίδα **έχει λήξει** (λήξη 31 Οκτωβρίου).
16. **Άλλα → Πελάτες** → θα πρέπει να δείτε 6 φανταστικούς πελάτες (Πελάτης Α … ΣΤ) με τηλέφωνο της μορφής +30 690 000 xxxx.
17. **Άλλα → Παραγγελίες → Αποστολή ανά πελάτη → χθες** → στο σπανάκι θα πρέπει να δείτε παραγγελίες **32** κλούβες ενώ συγκομίστηκαν **24**· το κενό φαίνεται.
18. **Άλλα → Ταμείο** → θα πρέπει να δείτε Έσοδα, Έξοδα και Καθαρό για τη χρονιά σε λεπτά του ευρώ (π.χ. 12,50 €), μία γραμμή «Επιστροφή ΦΠΑ» (ετικέτα εσόδου, χωρίς υπολογισμό φόρου) και σε μια εγγραφή το ιστορικό «Διόρθωση ποσού»· η ακυρωμένη εγγραφή δεν μετρά.
19. **Σήμερα → Εργασίες** και **Άλλα → Εργάτες** → θα πρέπει να δείτε 3 εργάτες (όνομα, επώνυμο, τηλέφωνο· **χωρίς ημερομηνία γέννησης**), 2 ελεύθερες δουλειές στον πίνακα, 2 δουλειές που ανέλαβαν εργάτες, 2 που **καθυστερούν**, και σημειώσεις για αύριο (μία με την ένδειξη «από εργάτη»).
20. **Άλλα → Φωτογραφίες** → θα πρέπει να δείτε 10 φωτογραφίες, καθεμία με γραμμή πηγής «δημιουργός · άδεια · Wikimedia Commons». Μετά **Άλλα → Διαγραφή επίδειξης** → θα πρέπει να μη μείνει κανένα στοιχείο της Επίδειξης και το πραγματικό σας κτήμα να είναι όπως ήταν.

**Αν κάτι διαφέρει**, γράψτε μου το βήμα και τι είδατε (π.χ. «βήμα 8: δεν είδα ψεκασμό σήμερα»).
