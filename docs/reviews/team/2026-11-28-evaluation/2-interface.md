## Score: 7 / 10

Why not lower: the measurable floor holds almost everywhere. 28 screen states × 4 widths: **zero horizontal overflow**, only **one** target under 44 px, no console errors, a tight runtime palette (24 computed colours across all owner screens) and only 7 distinct radii, no inline `style=`/hex in any `.tsx`, first-load JS inside its budget, a real «Φως ημέρας» mode, reduced-motion handled. That is better than most apps of this size.

Why not higher: the guards that are claimed to make this permanent cover only part of the code, and the gaps already let real defects in: an **undefined spacing token** (`--sp-3`) silently zeroes the margins of 8 cards; a **1.36 : 1 text contrast** on the «rejected by server» mark; **13.3 px text** on the two most-used detail screens; the HTML **splash logo never disappears** and sits under every screen; the worker **72 px rule** is met only for an allow-list of 7 buttons, not for the harvest crop chips the worker taps most; ~55 literal lengths/colours in the side CSS files that the «tokens only» test never reads; 22 tokens declared twice and two parallel type scales. The UX-bar test that is supposed to catch fonts/targets/axe "on every screen" visits 10 routes and none of the detail screens or sheets where the defects are.

## Environment improvements (so these do not come back)

- **ENV-1 Token test over all CSS.** `tokens.test.ts` and `css-sizes.test.ts` must glob `src/ui/**/*.css` (not just `styles.css`), with an explicit allow-list for print files. Better: **stylelint** with `scale-unlimited/declaration-strict-value` on `color, background-color, font-size, margin*, padding*, gap, border-radius, min-height, box-shadow` and `ignoreValues: [0, auto, inherit, currentColor, 100%]`, run in the `static` job.
- **ENV-2 Unknown custom properties fail.** Unit test: every `var(--x)` in every CSS/TSX file has a definition (tokens.css or a locally-scoped one). Would have caught `--sp-3` (8 rules). Also `declaration-block-no-duplicate-custom-properties` (stylelint) for the 22 twins.
- **ENV-3 Contrast per rule, not per listed pair.** Parse every CSS rule that sets both `color` and `background(-color)` (resolving `var()` from tokens.css, incl. fallbacks) and require ≥7:1 text (the project's own bar); fail when a rule's pair is not computable. Would have caught UI-01.
- **ENV-4 UX-bar visits the screens that matter.** `tests/e2e/helpers/iphone.ts` `ROUTES` has 10 entries and no detail screen/sheet; `ux-bar.spec.ts` target selector omits `summary` and `[role=button]` is the only role. Add: crop detail, parcel detail, crop guide, product sheet, weather sheet, quick-add, spray/harvest/observe/tomorrow forms, worker jobs/harvest/observe — with the **full-season** Demo (the current helper loads the small demo). Add `summary, [role=tab], [role=switch]` to targets; worker-app subtree uses 72.
- **ENV-5 First-load budget as a ratchet.** Store the measured bytes in a committed JSON; the test fails if size grows >2 % over it, and the JSON may only go *down* unless the PR adds a DECISIONS.md line (mirrors the `MAX_KNOWN_LIMITS` rule). Also report total first-visit transfer (fonts + prefetched chunks) as an annotation.
- **ENV-6 Boot-DOM check.** e2e: after first render, `#app` contains exactly one root and no `.splash` (UI-03).
- **ENV-7 `npm run ui-scan`.** Commit a script like `work-ui/scan.js` that prints the measured-numbers table above for the PR body (overflow, targets, fonts, axe, page height per screen at 320/375/390/768). QUALITY.md §8 already asks for evidence; this makes it one command.
- **ENV-8 Colour constants outside `src/ui`.** Extend the hex check to `src/**/*.ts` and `index.html`, with `share/card.ts` importing from a generated `tokens.ts`.
