Local PostgreSQL 16 (bare, no RLS, no Supabase), 100 synthetic farms × 300 days = 30,000 `weather_daily` rows, rolled back afterwards. Query: one farm, 30 days (the shape of the 0029 weather read). Codex measured the same table under RLS on PG 17 (8,800 → 88 index candidates); this is an independent check of the same direction, not production.

The server-side function change (`private.has_role`) has `search_path = pg_catalog, pg_temp` instead of Codex's empty path: the 0022 test requires `pg_temp` to be listed, and the body is fully schema-qualified either way. Tests: `supabase/tests/m16_hardening.sql` (red against 0034, green with 0035; real `authenticated` owner, worker and stranger).
