# Naming council, round 1: social media strategist (2026-11-17)

Lens: one handle on every platform (X allows only letters, digits and `_`, max 15 characters, so the handle uses only those), one spelling whether typed on a Greek or a Latin keyboard, a hashtag we can own, safe for Meta ads, easy to say in a voice note in a farmers' Facebook or WhatsApp group, and hard to mock.

The biggest risk for Greek names is **transliteration**: χ, η, υ, β each have 2–3 Latin spellings. Every "Ch-" or "-b-/-v-" name splits searches and handles.

## Ranked candidates

**1. Mera / Μέρα** ("day"). Handle: `@merafarm`.
Every letter maps one-to-one (Μ-έ-ρ-α = M-e-r-a), so there is no spelling ambiguity. In Turkish *mera* means "pasture", so it reads well for the Turkey phase. It echoes Megara and the app's "Today" screen ("η μέρα σου στο χωράφι"). It works in a voice note and in "καλημέρα" posts, so mockery tends to turn positive.
Risks: #mera is crowded (Aquaman's Mera, Hindi "my"), so we own **#merafarm** instead. The bare handle is taken. Still to check with Albanian, Bulgarian and Arabic speakers.

**2. Agros / Αγρός** ("field"). Handle: `@agrosapp`.
Clean one-to-one spelling, and every farmer already says it.
Risks: very generic, because co-ops, agrochemical shops and a Cypriot village already use it, so search and ownership are weak. "Aggro" is English slang for trouble.

**3. Lahano / Λάχανο** ("cabbage", the root of λαχανικά, "vegetables"). Handle: `@lahanoapp`.
The same word exists in Turkish (*lahana*). It's friendly, visual (an easy emoji or mascot) and fits a leafy-greens grower.
Risks: χ can be spelled h or ch, so `@lachanoapp` must be registered too. In English, "cabbage" is slang for a dull person. It's a light, jokey brand, so it may sound less serious next to an inspection-ready spray record.

**4. Chorafi / Χωράφι** ("field"). Handle: `@chorafiapp` (also secure `horafi`, `xorafi`).
Warm, and it's what farmers say every day.
Risks: three Latin spellings in active use. **#χωράφι is flooded with land-for-sale listings** ("πωλείται χωράφι"), so our posts would sink there and ad targeting would pull in real-estate audiences.

**5. SunField.** Handle: `@sunfieldapp`.
One-to-one in Latin script and easy in English and Turkish.
Risks: **crisis risk.** In Greek farmer groups, solar parks taking over farmland is a sore subject, and "SunField" sounds like a photovoltaic company. Mocking it is easy ("οι φωτοβολταϊκοί"). #sunfield is already used by solar firms and Sunfield, Michigan. Nobody will type it in Greek letters.

## Previously floated names

- **Tetradio / Τετράδιο** ("notebook"): clean spelling, but the hashtag and ad targeting are dominated by school stationery. It's dull to share.
- **Kloubes Agros:** two words is too long for a handle, and β can be spelled b or v (the repo itself uses `klouves`). Keep "Κλούβες" as the sister app's name rather than in this one.
- **Avoid "Kasa"** (Turkish for "crate"): in Greek, κάσα colloquially means "coffin".

## Next step

For the top 3: check that the handle is free on Instagram, TikTok, Facebook, YouTube and X. Check the .gr and .app domains. Search EUIPO class 9/42. Run a 10-second voice-note test with 3 farmers and 2 workers.
